Welcome to the GitHub repository of the [Cell Migration Lab](https://cellmig.org/)! Our lab is dedicated to understanding cell migration, focusing on cancer research. We also develop image analysis tools to advance this field.

## About us
The cell migration lab is located in Turku, Finland. The lab started in 2019 and is part of the Cell Biology department at [Åbo Akademi University](https://www.abo.fi/en/). We are part of [Turku Bioscience Centre](https://bioscience.fi/), the [IMMENs Centre of Excellence](https://www.helsinki.fi/en/researchgroups/immune-endothelial-interfaces) and the [INFLAMES Flagship](https://inflames.utu.fi/).

## [Software Projects](https://cellmig.org/software/)

At the Cell Migration Lab, we develop, co-develop, and contribute to software for microscopy and image analysis.

- **NucleiSky (2026)**: Image registration and ROI matching for microscopy images using nuclei constellations. [Paper](https://doi.org/10.64898/2026.06.29.735028) · [GitHub](https://github.com/CellMigrationLab/NucleiSky)
- **LabConstrictor (2026)**: From Jupyter Notebook to Desktop App in One Click [Paper](https://doi.org/10.48550/arXiv.2603.10704) · [GitHub](https://github.com/CellMigrationLab/LabConstrictor)
- **EZInput (2026)**: a Python library that simplifies the creation of graphical user interfaces [Paper](https://doi.org/10.48550/arXiv.2601.08859) · [GitHub](https://github.com/HenriquesLab/EZInput)
- **SReD (2025)**: Structural Repetition Detector Plugin for ImageJ and Fiji [Paper](https://doi.org/10.1038/s41467-025-60709-1) · [GitHub](https://github.com/HenriquesLab/SReD)
- **Rxiv-Maker (2025)**: a toolbox that converts markdown into a publication-ready PDF [Paper](https://doi.org/10.1242/jcs.265183) · [GitHub](https://github.com/HenriquesLab/rxiv-maker)
- **PhotoFiTT (2024)**: Phototoxicity Fitness Time Trial. A Quantitative Framework for Assessing Phototoxicity in Live-Cells. [Paper](https://doi.org/10.1038/s41467-025-66209-6) · [GitHub](https://github.com/HenriquesLab/PhotoFiTT)
- **NanoPyx (2024)**: A library for analyzing light microscopy and super-resolution data, successor to NanoJ. [Paper](https://doi.org/10.1038/s41592-024-02562-6) · [GitHub](https://github.com/HenriquesLab/NanoPyx)
- **DL4MicEverywhere (2024)**: An extension of ZeroCostDL4Mic featuring interactive Jupyter notebooks for bioimage analysis using deep learning. [Paper](https://doi.org/10.1038/s41592-024-02295-6) · [GitHub](https://github.com/HenriquesLab/DL4MicEverywhere)
- **CellTracksColab (2024)**: A platform for compiling, analyzing, and exploring tracking data. [Paper](https://doi.org/10.1371/journal.pbio.3002740) · [GitHub](https://github.com/CellMigrationLab/CellTracksColab)
- **eSRRF (2023)**: Provides a super-resolution approach and optimal parameter prediction for super-resolution microscopy. [Paper](https://doi.org/10.1038/s41592-023-02057-w) · [GitHub](https://github.com/HenriquesLab/NanoJ-eSRRF)
- **Fast4DReg (2023)**: A Fiji plugin for 2D and 3D video drift correction in all axes. [Paper](https://doi.org/10.1242/jcs.260728) · [GitHub](https://github.com/CellMigrationLab/Fast4DReg)
- **TrackMate (2022)**: Automated tracking software analyzing bioimages, distributed as a Fiji plugin. [Paper](https://doi.org/10.1038/s41592-022-01507-1) · [GitHub](https://github.com/trackmate-sc/TrackMate)
- **ZeroCostDL4Mic (2021)**: Allows the use of popular deep-learning neural networks for tasks in bioimage analysis. [Paper](https://doi.org/10.1038/s41467-021-22518-0) · [GitHub](https://github.com/HenriquesLab/ZeroCostDL4Mic)
- **FiloMap (2019)**: ImageJ and R scripts for mapping protein localization within filopodia. [Paper](https://doi.org/10.1016/j.cub.2018.11.053) · [GitHub](https://github.com/CellMigrationLab/FiloMAP)
- **FiloQuant (2017)**: A Fiji plugin for automated detection and quantification of filopodia properties. [Paper](https://doi.org/10.1083/jcb.201704045) · [GitHub](https://github.com/CellMigrationLab/FiloQuant)
- **SRRF TFM (2020)**: Enhances the output of traction force microscopy using super-resolution microscopy. [Paper](https://doi.org/10.1021/acsnano.9b07628)

For more details on each project, visit our [software page](https://cellmig.org/software/).
